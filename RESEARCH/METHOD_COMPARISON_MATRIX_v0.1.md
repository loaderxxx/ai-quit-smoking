# Матрица методов отказа от курения — v0.1

Дата: 2026-09-23

| Метод | Доказательная картина | Что даёт программе | Ограничение |
|---|---|---|---|
| Консультирование | Высокая уверенность в пользе | Поведенческий core | Нельзя автоматически считать AI эквивалентом консультанта |
| НЗТ | Высокая уверенность в эффективности; комбинация форм часто лучше одной | Контроль никотиновой тяги | Требуется безопасный подбор |
| Варениклин | Высокая уверенность в эффективности по ключевым сравнениям | Сильный фармакологический вариант | Медицинский контекст |
| Цитизин / цитизиниклин | Эффективен; современно включён в руководства | Дополнительный фармакологический вариант | Доступность и клинические ограничения |
| Бупропион | Эффективен | Дополнительный вариант | Сравнительно слабее некоторых альтернатив |
| Никотиновые e-cigarettes | Cochrane 2026: выше quit-rate против НЗТ; безопасность долгосрочно требует дальнейшего изучения | Потенциальный переходный вариант | Быстро меняющаяся evidence/regulatory среда |
| Текстовые сообщения | Польза в Cochrane review | Цифровая доставка поддержки | Не всякая AI-функция доказана |
| Интернет-программы | Интерактивность/адаптация может помогать | Онлайн-поддержка | Эффект зависит от дизайна |
| Финансовые стимулы | Высокая уверенность в пользе в смешанных популяциях | Commitment layer | Требуется этичная механика |
| Группы | Лучше простой самопомощи в части исследований | Социальная поддержка | Не доказано превосходство над индивидуальной сопоставимой интенсивностью |
| Самопомощь | Небольшая польза без другой поддержки | Контентный слой | Не заменяет сопровождение |
| Mindfulness | Ясного преимущества не установлено | Дополнительный coping-инструмент | Низкая/очень низкая уверенность |
| Motivational interviewing | Недостаточно уверенности в самостоятельном эффекте | Стиль диалога | Не делать доказанным core-механизмом |
| Резкий отказ | Систематические данные не показывают универсального превосходства над снижением | Подходит как явный Day 1 | Не единственный допустимый путь |
| Постепенное снижение | Может быть сопоставимо с резким отказом | Альтернативный путь до quit date | Нужна конечная точка полного отказа |

## Текущая архитектурная гипотеза

Публичная программа должна не выбирать единственный метод, а использовать decision layer:

ПРОФИЛЬ → ПРЕДПОЧТЕНИЯ → РИСКИ → ДОСТУПНОСТЬ → ДОКАЗАТЕЛЬСТВА → ПЛАН → НАБЛЮДЕНИЕ → АДАПТАЦИЯ

Это гипотеза архитектуры, а не клиническая рекомендация.
